# Security policy

This repository is an experimental board port. No security-maintenance or vulnerability-response SLA is offered, and it must not be treated as a hardened production router image.

Please **do not post** private keys, OEM signing material, factory credentials, serial numbers, MAC addresses, IMEI, unique calibration data, access tokens, or full raw partition dumps in public issues or PRs. Redact logs before sharing.

For suspected vulnerabilities, use GitHub's private vulnerability reporting feature **if enabled** for the repository. If not available, open a minimal issue requesting a private contact channel without publishing exploit details or sensitive data.

Releases (when available) should list upstream security baseline, included packages, known limitations, image hashes and build provenance. Do not trust unsigned/unverified binaries claiming association with this project.
