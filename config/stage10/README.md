# Stage 10 kernel configuration: intentional exclusion

The experimental booted-image configuration is retained in a **separate, permanently Private research archive**. Its exact SHA-256 is listed in [sanitized provenance](../../docs/evidence/lte-stage10.json).

It is NOT redistributed here because it contains research-machine path information and forced developer-oriented boot options tied to a particular environment. Merely replacing those values would break the original configuration hash and would not create a reliable public build.

Reproduction requires a separately authored, reviewed kernel configuration along with redistributable Device Tree, source, OpenWrt rootfs and modem runtime. No substitute, dummy input or inferred configuration is presented as a verified equivalent.
