# SoftBank Air Terminal 6 OpenWrt Alpha 3 RC1 Developer Preview

**2026-11-02 | Source and technical status preview | Experimental research, not installable firmware**

This is an independent community project working toward OpenWrt support for **SoftBank Air Terminal 6 (A775 / MediaTek MT6990)**. This Developer Preview shares **what the development team has learned, what source is already publicly reviewable, and where collaborators can help**. It is **not** a firmware image download, supported installation procedure, or an announcement of a verified Alpha 3 boot on a new device.

**Current public release state:** **Alpha 3 RC1 Developer Preview / source and technical status**. A publicly redistributable signed p25/p26, a validated C-device boot result, and a safe independently proven rollback are **not announced or provided here**. Privately retained research candidates, if produced later, are subject to distinct owner approval and cannot be assumed to be public firmware releases.

## Why Alpha 3?

The project already has historical development-device results with Linux, Ethernet, local SSH management, 2.4/5 GHz Wi-Fi and LTE IPv4 traffic. Alpha 3 focuses on **reusing and stabilizing successful work**, rather than adding another layer of features. The immediate research target is deliberately small: get a Linux 6.18.44 kernel to hand control to the RAM-only OpenWrt initialization sequence and **procd as PID 1** on the designated C development unit.

The preceding Alpha 2 and Test27 work provides valuable comparison data. It does not establish that the newer C-unit Alpha 3 RC1 has booted, or that a public-tree rebuild reproduces all the historical private results.

The private research source archive and individual OEM/firmware/signing materials are **not** reproduced, linked as publicly downloadable files, or copied into this repository. Offline success is distinct from hardware success; a successful QEMU boot is not an actual Air6 boot.

## Alpha 3 first-boot sequence

The **Phase 1 goal** has five observable steps:

1. **Bootloader-to-Linux handoff**. The bootloader actually transfers execution to Linux.
2. **Linux banner** reports the expected **Linux 6.18.44** kernel.
3. **RAM `/init`** executes from the embedded initramfs.
4. **OpenWrt preinit** executes.
5. **procd is PID 1**, supported by observations of the **same boot session**, not merely by spotting a log message containing “procd”.

Phase 1 does **not** require a working Ethernet cable, SSH login, Wi-Fi association, LTE modem, 5G NR, or persistent root filesystem. This separation makes a genuine first-boot result easier to interpret.

**Later phases** will independently address matching-kernel Ethernet/SGMII1/MT7531 and safe SSH, 2.4/5 GHz access points, full OpenWrt service rootfs, persistent startup and recoverability, then modem and additional capabilities where lawful and technically supported.

## Can I test Alpha 3 today?

**You can review the public source and run the documented, non-device tests. You cannot download a verified, generally installable Alpha 3 RC1 firmware from this page.** No universal flashing instructions, bootloader authorization, signing materials, device-specific firmware, Wi-Fi calibration, subscriber credentials or rescue guarantees are included.

Anyone seeking to discuss experimental access or share privately held test observations should start at [Discussions #50: getting started and test interest](https://github.com/Karin-Laboratory/openwrt-terminal-6/discussions/50). That conversation is **not a download guarantee**. Do not post personal identifiers, device secrets, non-public exploits, raw OEM partitions or credentials in a public thread. Any separate, owner-approved private exchange has its own terms and release checks.

### What would help most?

- **Review publicly available source** for Linux/MT6990 clock, PHY, PCS1, MDIO/DSA and Ethernet path correctness.
- **Review the OpenWrt build separation** so a device-specific SBAT6 target does not accidentally import another product's boot/rootfs configuration.
- **Share reproducible, non-sensitive diagnostics** for ordinary Linux/OpenWrt issues, and make source-only changes through [CONTRIBUTING.md](../CONTRIBUTING.md).
- **Help refine rights/provenance records** so third-party code and firmware are shared only where authorized.

For problems involving firmware signature bypass, proprietary OEM files or chip-unique calibration, please follow [SECURITY.md](../SECURITY.md) rather than posting raw materials in Issues or Discussions.

## Feature and release boundaries

There is **no claim of completed 5G NR, modem IPv6, 6 GHz client connectivity, Wi-Fi 7 EHT/MLO, EasyMesh, production security, repeatable cold boot, or safe recovery**. These are separate engineering milestones. Results obtained with historical B hardware are not represented as new Alpha 3 C hardware results.

The current publication **adds original explanatory Markdown only**. Existing source licenses remain file-specific: Linux-derived patches are GPL-2.0-only where marked, independent examples may use MIT, and per-file contributor/redistribution rights review is ongoing. **Source visibility and permission to distribute an installable binary are separate decisions.** See [PROVENANCE.md](PROVENANCE.md) and [RELEASE-GATES.md](RELEASE-GATES.md).
