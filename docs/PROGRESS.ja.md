これらはプロジェクト内で報告された実機成果です。公開された完全な生ログや第三者による独立検証ではありません。

## 有線LANで分かったこと

開発機で報告された接続は `MAC1 → SGMII1 → MT7531 CPU port 5 → user port 1 (lan2)` です。Raspberry Pi 2へのRJ45直結では100 Mb/sリンク、双方向ping・SSH・データ転送が確認されたと報告されています。

**内部のSGMIIリンク設定と外部RJ45のリンク速度は別物**です。この観測はRJ45での2.5GbE対応を証明しません。PLLや電源ドメインを共有するため、独立したドライバの起動・停止処理にも追加検証が必要です。
