# AP-first milestone: standalone unsigned AArch64 PID1 initramfs

**Scope: real, non-installable ARM64 initramfs construction, not an OpenWrt rootfs, Air6 kernel Image, Air6 DTB, AP or hardware boot.** Tracks #74 / #21 / #4.

`python3 scripts/build-minimal-arm64-initramfs.py /path/to/new-empty-output-directory` compiles the independently authored `scripts/air6-diagnostic-init.c` as a **static AArch64 ELF64 ET_EXEC** using preinstalled `clang` and `ld.lld`, with no libc or dynamic loader. It creates a deterministic Linux `newc` archive with `/init` (PID1), `/dev/console` (5:1), `/dev/null` (1:3), `/proc` and `/sys`. PID1 writes a diagnostic banner and sleeps forever. It does not mount, configure networking, expose SSH, alter partitions or perform recovery. The archive is compressed with gzip mtime=0.

The output directory must not exist beforehand; privileged execution is refused. The tool never downloads, signs, flashes, executes the cross-built binary, or uploads artifacts. `manifest.json` records the compiler/linker versions, source SHA-256, ELF SHA-256 and compressed initramfs SHA-256. GitHub-hosted source-only CI **actually cross-compiles and archives** this object in an ephemeral directory and deletes it after verification. No binary is committed or distributed. For reproducibility across machines, pin the compiler/linker version and verify the manifest: gzip timestamp normalization alone does not make cross-toolchain outputs universally byte-identical.

**Next required integration:** independently rights-cleared Linux 6.18 MT6990 kernel configuration, matching Air6 board DTS/SoC DTSI and providers, actual `Image` plus DTB build and `dtbs_check`; then boot the combined Image/DTB/initramfs offline in a suitable isolated emulator if supported. This tiny diagnostic PID1 is intentionally not OpenWrt `procd` and contains no AP stack. Separately build a native SBAT6 OpenWrt rootfs and integrate Ethernet/2.4+5 GHz radio inputs with rights review. Historic private 6.18.44 LAN/SSH/AP successes are valid historical observations, not proof for this new public source.

**Safety and legal gates:** all new source-catalog entries remain `rights_review=pending`. This work neither proves source redistribution clearance nor authorizes an installable image, LK/Preloader modification, boot-slot write, signing, private firmware, calibration/EEPROM import or any device action.
