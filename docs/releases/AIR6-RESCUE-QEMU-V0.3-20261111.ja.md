# Air6 Rescue P43/P44 v0.3 — QEMU検証済み、実機未検証（2026-11-11）

**配布区分: 実験版 / Pre-release / QEMU ONLY / Hardware NOT TESTED**

これはSoftBank Air Terminal 6 (SBA6D) 向けP43/P44再分割のための**仮想ディスク検証ツール**の公開記録。**実機用ファームウェア、実機用インストーラ、署名済みP25/P26、書込み手順ではない。** これらを含むと解釈してはいけない。独立の公式OpenWrtリリースでもない。

## 実績
- Raspberry Pi 4上のQEMU/KVM、AArch64 Debian 6.12.116 + BusyBox initramfs環境で起動
- 仮想P43 ext4: 771312×4096バイト（約2.94GiB）から112640×4096バイト（440MiB）へ実縮小
- P43のGPT領域を453MiBとし、P44約2.5GiBを新設・ext4初期化
- P43に格納した200MiBペイロードを維持し、独立監査でSHA256一致:
  `ca144fc53fd18cdec511d98579ea8700eb600c5f75cfe3b41c2a0e397c3dd939`
- 完成済みディスクの再実行でP44の再初期化を回避
- `after-resize`, `after-gpt`, `before-format` の**工程境界**における意図的停止・再開を確認

## 重大な制限
- **純正未分割の実機テストはゼロ**。純正基準機A号機は保存する。B号機/C号機はすでに分割済み。
- QEMUモデルはP1〜P42を省略し、固定の試験用GUID・容量と `/dev/vda` を前提とする。実機eMMCのGPT/パーティションと同等ではない。
- `resize2fs`、GPT更新、`mkfs.ext4`の**書込み途中**の強制電源断試験は未実施。
- QEMUカーネルはAir6 MT6990/LK用起動イメージではなく、実機レスキューP25、DTB、ネットワーク復帰、UARTなし起動は未検証。
- P43を純正OS稼働中に縮小することはできない。実機で実行すればデータ喪失・起動不能の恐れがある。
- **`/dev/vda` を `/dev/mmcblk0` に置換するだけで実機適用することを禁止**。P43のGUIDや状態の解釈も固定値のままでは不適合。
- rootアクセス取得方法、署名鍵、校正データ、純正ダンプ、実機用フラッシュ可能なイメージは配布しない。

## リリース目的

本配布は、所有端末での移植を研究する開発協力者がQEMU上で処理・データ保全・再実行挙動を再現するためのもの。個体への実機適用を推奨するものではない。実機でのインストール可能性や安全性を保証しない。
