## Minimal dependency chain for a real unsigned AP build

1. **#20: matching kernel support.** Record exact legal source revisions, Git blobs and SHA-256 of each *actual* MT6990 clock/reset/genpd/NETSYS/PCS/PHY/pinctrl/PCIe provider and their compatible bindings. Compile in one pinned Kbuild tree with the board DTS; investigate `dtbs_check` findings individually. Explicitly list unavailable source rather than silently borrowing an LG6851F image. Generic ARM64 compilation does not close this gate.
2. **#21: distinct SBAT6 userspace.** Build reproducible, non-installable rootfs with a native board profile, essential network/bridge/SSH/AP packages, explicit first-boot credential policy and no vendor runtime or factory secrets. Feed locks and BusyBox smoke alone do not close this gate.
3. **#20/#21/#4: Ethernet and Wi-Fi integration.** Prove MAC1/PCS1/MT7531 ownership and DTB wiring. Research per-device Wi-Fi calibration/EEPROM extraction and redistribution rights, including MAC provisioning, firmware source and PCIe mapping. Record configuration and output hashes; distinguish `BUILD_PASS` from `DEVICE_PASS`.
4. **#74: separately authorized device acceptance.** At least three cold boots with Ethernet upstream, AP 2.4/5 GHz, client traffic, management and persistence, without manual register repair. Release/signing/flash and hardware operations remain outside the autonomous/public CI scope.

## Evidence conventions for future device runs

Propose one sanitized JSON record *per boot* with: source commit, kernel/DTB/rootfs SHA-256, build ID, boot cycle ordinal, observed slot (only if safe to disclose), Ethernet physical link, ARP/ping/SSH, AP association and data on 2.4/5 GHz, DHCP and persistence, diagnostics with redacted identifiers, status `PASS/FAIL/NOT_TESTED`, and a separate recovery observation. Do not synthesize an observed result in advance. Exact fields and privacy review belong to the owner-operated test plan.

**Priority:** close the nearest *real missing source/build dependency*, not another generic guard-only PR. This note is a triage record and does not satisfy any checkbox in #74 by itself.
