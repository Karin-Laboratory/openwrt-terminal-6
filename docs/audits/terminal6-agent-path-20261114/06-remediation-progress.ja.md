## オフライン検査器の契約
- `--input`で受け取るJSON以外は読み込まない。外部コマンド、UART、`/dev`を一切操作しない。
- `INSPECT_ONLY_NO_DEVICE_PASS` は観測値に明白な矛盾が無い**予備判定**であり、S06 PASSやS07実行許可ではない。
- 不足情報、P43容量不足、マウント、journal所見、未検証バックアップ、P43に依存したSSH永続化でBLOCKEDを返す。
- P44が既存なら再作成をすすめず、検証分岐にする。
- 観測資料の公開時には個体識別子・秘密情報を除外する。

**総合判定はまだ NOT READY。** 公開側の最初のBLOCKEDはS03のまま。ただし、それ以降の危険な誤判断につながる資料とオフライン判定を改善した。
