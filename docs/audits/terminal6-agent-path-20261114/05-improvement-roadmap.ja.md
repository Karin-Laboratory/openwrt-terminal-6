# 05. 完走可能にするための改善ロードマップ

目標は **S08 まで初見AIが完走できる導線**。安全停止の確認だけではない。各フェーズは**終了条件（ゲート）**を持ち、ゲートを満たした時だけ判定を上げる。

## 判定の上げ方（ゲート）

| 判定 | 条件 |
|---|---|
| NOT READY → **PARTIALLY READY** | S01〜S03 が文書だけで進められ（S03 到達手順の公開）、S04〜S08 の現状が機械可読で宣言され、初見AIが S03 の先で実機に触れる前に止まれる |
| PARTIALLY READY → **READY** | S04〜S08 すべてに公開資料と実装があり、実機検証を残すのみ（HW-01〜07 以外の欠落がない） |
| READY → 完走認定 | 新規個体で S08 まで通し、電源断試験を含めて独立に確認（D 完了） |

## 優先順位の理由

1. **フェーズ0** は費用が小さく、誤認を即座に防ぐ。初見AIが実機に触れる前に止まれるようにする効果が最も大きい。
2. **S03 の到達手順（1-1/1-2）** が最初の BLOCKED を外す唯一の手段。ただし**ブート制御に関わるため公開は所有者判断**。
3. **未分割向けの読取り専用モード（2-1）** が S06 の完走に必須。書込みの前に必ず必要で、リスクが最も低い実装でもある。
4. 実機での書込み系（3-5）は**最後**。フェーズ2の電源断試験が通るまで行わない。
