# 04. 公開・非公開記録の整合性監査

公開資料の記述を、非公開アーカイブ（PR #150 のブランチ、PR #155、Issue #116 と C号機 slot B 復旧の記録、N号機仮想分割記録、RC15 方針）と照合した。**非公開側は実機の再観測ではなく記録の読解**である。非公開の内容は、公開してよい粒度に要約している。

## 1. 一致を確認した項目（誤認なし）

| 公開側の記述 | 非公開側の確認結果 | 判定 |
|---|---|---|
| v0.4 `installer.sh --apply` は意図的に拒否する | 実装は終了コード77で拒否、`--check` は preflight を呼ぶのみ | 一致 |
| r3 は疑似UART搬送・再送・SHA・QEMU起動の検証のみ | 結果JSONで実UART・実機ELF実行・未分割・電源断・`DISTRIBUTION_READY` はすべて NOT_TESTED／NO | 一致 |
| QEMU で 2.94GiB→440MiB 縮小、GPT 453MiB、P44 約2.5GiB、200MiB のSHA保持 | リリースメモ・検証記録に同一の値とSHA。使用量 70,933/112,640 ブロック。「実機ではない」と明記 | 一致 |
| 公開QEMUスクリプトは QEMU 専用 | 非公開の v0.2 スクリプトと**機能上同一**（差分はコメント・空白のみ） | 一致 |
| PR #155 は Debian slot A の成功で、純正 slot B の初期SSH・P43分割ではない | PR #155 の内容は slot A Debian の Ethernet/SSH/Wi-Fi PHY 永続化とブート制御の実機結果。純正 slot B は変更なしと明記 | 一致 |
| 開発個体の P43 に `e2fsck -fn` の所見があり原因は未確定 | 非公開の README・結果に同旨 | 一致 |
| RC16 は P44 を前提とし、分割ツールを含まない | 公開リリースの本文と一致 | 一致 |

**総評:** 入口JSONと関連公開文書の**主張は、非公開の証拠を過大評価していない**。誤PASSや誇張は見つからなかった。

## 2. 不一致・矛盾・誤認（要対応）

## 4. 公開側にあり、非公開で裏付けが見つからなかったもの

|---|---|
| 「分割後の実測例 P43 GPT 約453MiB・ext4 約440MiB・P44 約2.5GiB は **CONFIRMED_ON_UNIT**」 | 非公開の記録は、この値を**仮想ディスク試験の最終配置**として記載。実機（分割済み B号機）で観測された値とどこまで同一かは、今回確認した記録では**直接照合できなかった**（UNVERIFIED）。分割済み個体の実測値が別途ある可能性はある |
| 「Linux 5.4.238 / AArch64」「通常起動で PID1=procd」 | 非公開の C号機記録で確認（OBSERVED_PRIVATE） |

## 5. 整合性監査の限界

- 非公開側の全コミット・全 Issue を読んだわけではない。確認した参照は本文の冒頭に記載した範囲。
- PR #150 に添付された Draft Release の ZIP の中身は展開していない。
- 公開側 CI の実行結果（GitHub Actions）は確認していない。
- 公開リポジトリの Discussion は取得できなかった。
