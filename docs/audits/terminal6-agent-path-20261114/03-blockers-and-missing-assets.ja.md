## 5. 公開できない（または慎重な判断が要る）もの

| 内容 | 理由 | 扱い |
|---|---|---|
| 非公開の初期アクセス手段（脆弱性に依存する経路） | 非公開の脆弱性情報 | **公開しない。** 代替として、UART 経由の正規の手順（Emergency Shell 経由）だけで成立する経路を設計する |
| ブート制御領域の生書込み位置・値 | 個体・FW差と誤操作リスク | 公開する場合も読取り専用の確認手順と承認ゲートに限定。所有者判断 |
| LK の内部コマンド手順 | 同上 | 所有者判断。許可/禁止の区分のみの公開から始める |
| 個体固有値（IP・鍵・ホスト鍵・MAC 等） | 個人情報・認証情報 | 公開しない |
| v0.4 同梱の GPL バイナリ | 対応ソース・通知が未整理 | 権利整理後に限り公開 |
