# Contributing

Small, reviewable contributions are welcome when accompanied by source origin and applicable license. Do not include proprietary SDK code, vendor binaries, confidential logs, personal device identifiers, passwords, radio calibration, signing keys, or actionable vulnerability details.

For kernel-derived work, retain GPL SPDX/copyright provenance and do not fabricate third-party Signed-off-by lines. Tests should run on isolated hosts without device access. Experimental device changes and firmware packaging are outside this repository's public contribution path.

Security reports should follow [SECURITY.md](SECURITY.md), not ordinary Issues.
